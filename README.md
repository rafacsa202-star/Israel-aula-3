    <h1>A Origem e Evolução da World Wide Web</h1>
    <!-- Parágrafo Introdutório -->
    <p>
        A <b>World Wide Web</b> (WWW) transformou radicalmente a forma como a humanidade compartilha informações. 
        Desenvolvida no final dos anos 1980, ela permitiu conectar computadores em todo o mundo através de documentos interligados.
    </p>
    <!-- Linha Horizontal de Separação -->
    <hr>
    <!-- Subtítulo de Nível 2 -->
    <h2>O Criador da Web</h2>
    <p>
        Em 1989, o cientista britânico <i>Tim Berners-Lee</i> inventou a Web enquanto trabalhava no <b>CERN</b> 
        (Organização Europeia para a Pesquisa Nuclear).<br>
        O objetivo inicial era permitir que cientistas de diferentes universidades e institutos ao redor do mundo 
        compartilhassem informações de forma automatizada.
    </p>
    <!-- Linha Horizontal de Separação -->
    <hr>
    <!-- Subtítulo de Nível 2 -->
    <h2>Principais Tecnologias Envolvidas</h2>
    <p>
        Para fazer a Web funcionar, foram criados três pilares fundamentais:<br>
        1. <b>HTML</b> (<i>HyperText Markup Language</i>) — A linguagem de marcação dos documentos.<br>
        2. <b>HTTP</b> (<i>HyperText Transfer Protocol</i>) — O protocolo de comunicação para transferência de dados.<br>
        3. <b>URL</b> (<i>Uniform Resource Locator</i>) — O endereço único de cada recurso na rede.
    </p>
    <p>
        Como o próprio Tim Berners-Lee declarou:<br>
        <q>A Web não é apenas para conectar computadores, é para conectar pessoas.</q>
    </p>
